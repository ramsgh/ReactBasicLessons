# React Basics Learning App

This project is a small React playground for learning core React concepts in a simple and visual way.

## Included examples

- Functional components
- Parent/child component composition
- Props and destructuring
- Children prop
- PropTypes validation
- Rendering lists with .map() and key
- Conditional rendering with ternary, &&, and switch

## Run the app locally

1. Open a terminal in the project folder.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev -- --host 0.0.0.0
```

4. Open the local URL shown in the terminal, usually:

```bash
http://localhost:5173/
```

## Build for production

```bash
npm run build
```

## Project structure

```bash
src/
  App.jsx
  App.css
  index.css
```

## Notes

This app is intentionally simple and beginner-friendly. Each section demonstrates one React idea so you can study the pattern and then modify the code to experiment on your own.
